# Site Quietkit — cum îl pui online gratuit

## 1. Date completate

## 2. Publică pe GitHub Pages
1. Creează un cont pe github.com (dacă nu ai).
2. New repository → numele **`<username>.github.io`** (ex: `quietkit.github.io`) → Public → Create.
3. „uploading an existing file” → trage toate fișierele din acest folder (index.html, privacy.html, terms.html, refund.html, styles.css, .nojekyll) → Commit.
4. Settings → Pages → Source: „Deploy from a branch”, branch `main`, folder `/ (root)` → Save.
5. În 1–2 minute site-ul e live la `https://<username>.github.io`.
